# Persistent Dice

画布右下角的八角骰盘，用于 PF2e 的检定与伤害。浅木框、暗酒红内衬，底面水平放置；从偏离正上方55°的桌面视角观察。盘中骰子与托盘共用35° FOV，原生 DsN 投掷相机保持不变。

1. 打开原生检定或伤害窗口，骰盘会显示本次需要的骰子。
2. 在骰盘内长按，拖出抓起整把骰子；拿起后不自动旋转，松手或轻甩都会投掷。
3. 全部落定后默认自动提交。原生 Roll 按钮随时可用。

短按不会投掷。Esc、失焦或关闭窗口取消抓取。键盘聚焦骰盘后按住空格，松开投掷。

松手前最近200ms内有至少3px的位移，就按屏幕上的拖动方向投掷，无需用力甩出。静止释放、停顿至少200ms后释放或键盘释放，会在松手时随机选一次方向。

公开投掷使用 DsN 显示的同一结果。DsN 在释放时生成随机数；手势影响运动，不影响随机分布。原生按钮仅采用当前会话已确认落定的结果，其余骰子按原生规则补齐。

准备、抓取、放大和投掷仅在发起者本地显示。公开聊天结果生成后，其他玩家的原生 DsN 动画沿物理投掷的大致方向播放，可能从屏外进入；原生偏转、相机和各自的 DsN 设置仍然生效。完整物理结果在发起者处不重复播放。部分物理结果、混合 Roll 或可见内联随机结果保留原生动画，本地已投骰可能再次展示。同一骰子项内的原生补骰沿用该项的方向。

性能优先：预览复用并预热原生 DsN persistent-dice 的纹理和着色器缓存，准备完成后才能抓取。拿起时沿用预览已经选好的配色，避免随机主题再次重建材质。盘内小骰只作静态展示，不创建物理体；同一批次内的位置和朝向按种子随机生成并保持固定。放大按实际经过的约150ms计算，由 DsN 已有动画循环绘制；不增加独立绘制循环或准备阶段的广播。GLB、逐面纹理等自定义外观保留原生材质路径。

私密检定保持原生流程。支持普通检定、原生武器/近战武器和法术伤害窗口；元素冲击、内联伤害及无标准窗口的重投保持原生流程。

设置：启用、骰盘尺寸、自动提交、详细日志。升级沿用现有启用和自动提交偏好，旧设置保留在数据库以便回退。

本版本只提供检定骰盘。GM 首次迁移至 0.5.1 时关闭 DsN 的世界级固定骰功能，保留原有保存数据，方便回退或另行恢复。旧的固定骰操作及远端持久骰兼容逻辑已退役。

**0.5.3** 已在 Foundry 14.368、PF2e 8.5.1、Dice So Nice 6.4.1 / 6.4.2、libWrapper 1.13.5.1 的隔离世界中验收。[性能 QA](docs/qa-performance-20261001.md) 记录抓取、方向、结果、资源和验证边界；[托盘 QA](docs/qa-tray-20261001.md) 记录视角、材质和220px实际尺寸。

开发检查：`npm ci`、`npm test`、`npm run check`。模块 API 提供 `diagnose()` 和不改角色/世界设置的 `runChecks()`。
