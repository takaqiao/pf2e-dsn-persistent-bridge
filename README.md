# Persistent Dice

画布右下角的八角骰盘，用于 PF2e 的检定与伤害。浅木框、暗酒红内衬，底面水平放置；从偏离正上方55°的桌面视角观察。盘中骰子与托盘共用35° FOV，原生 DsN 投掷相机保持不变。

1. 打开原生检定或伤害窗口，骰盘会显示本次需要的骰子。
2. 在骰盘内长按，拖出抓起整把骰子；松手或甩出投掷。
3. 全部落定后默认自动提交。原生 Roll 按钮随时可用。

短按不会投掷。Esc、失焦或关闭窗口取消抓取。键盘聚焦骰盘后按住空格，松开投掷。

公开投掷使用 DsN 显示的同一结果。DsN 在释放时生成随机数；手势影响运动，不影响随机分布。原生按钮仅采用当前会话已确认落定的结果，其余骰子按原生规则补齐。

准备、抓取、放大、旋转和投掷仅在发起者本地显示。公开聊天结果生成后，其他玩家按各自 DsN 设置播放原生动画；完整物理结果在发起者处不重复播放。部分物理结果、混合 Roll 或可见内联随机结果保留原生动画，本地已投骰可能再次展示。放大按实际经过的约 150ms 计算，由 DsN 已有动画循环绘制。

私密检定保持原生流程。支持普通检定、原生武器/近战武器和法术伤害窗口；元素冲击、内联伤害及无标准窗口的重投保持原生流程。

设置：启用、骰盘尺寸、自动提交、详细日志。升级沿用现有启用和自动提交偏好，旧设置保留在数据库以便回退。

本版本只提供检定骰盘。GM 首次迁移至 0.5.1 时关闭 DsN 的世界级固定骰功能，保留原有保存数据，方便回退或另行恢复。旧的固定骰操作及远端持久骰兼容逻辑已退役。

本地候选版本 **0.5.2**，验证目标：Foundry 14.368、PF2e 8.5.1、Dice So Nice 6.4.1、libWrapper 1.13.5.1。尚未发布；manifest 中的 v0.5.2 下载地址是候选版本地址。[0.5.2 QA](docs/qa-tray-20261001.md) 记录视角、材质和实际尺寸；[0.5.1 QA](docs/qa-local-20261001.md) 记录本地投掷、聊天动画、迁移及测量边界；[旧 QA](docs/qa-20260930.md) 属于 0.5.0。

开发检查：`npm ci`、`npm test`、`npm run check`。模块 API 提供 `diagnose()` 和不改角色/世界设置的 `runChecks()`。
