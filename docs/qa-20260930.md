### 消息模式测试修正

当前原生 GM 模式枚举使用 **`gm`**。旧的 `private` 字串不是该原生模式，传入 PF2e 后会归回 `public`。

因此，`private-native`（消息 `DZTef5QaTNjnPwDq`）和 `private-native-stable`（消息 `uEOU1hR9ElQsiUPf`）**均为无效的 GM 隐私测试，不能计作通过**。它们的 revision 为 null、`taskThrow = false`，不足以证明消息权限或公开广播中没有秘密值。

早期真正 `gm` 的消息 `rMqUpj9smbdytZtq` 记录了 18 + 5 = **23**、revision = null。追加复验使用真实 `gm`／`blind`／`self` 枚举，结果保留原生路径，不产生公开 persistent-throw：

| 模式 | 原生结果与目标消息 | 物理广播与清理 | 结论 |
| --- | --- | --- | --- |
| `gm` | d20 = 18；总计 **23**；`WIA4WUnm0kVygDLt` | throws = 0；revision = null；session／owned／dialog = 0 | GM 模式原生回退与无公开任务投掷通过 |
| `blind` | d20 = 20；总计 **25**；`X2kS5VyiY3qMsNRI`；blind = true | throws = 0；revision = null；session／owned／dialog = 0 | Blind 原生回退与无公开任务投掷通过 |
| `self` | d20 = 12；总计 **17**；`JA9btBYkFDD8l1J2` | throws = 0；revision = null；session／owned／dialog = 0 | Self 原生回退与无公开任务投掷通过 |

`privacy-final.json` 的总 throws 列表为空，三个案例的 activeMode 均为 null。这里通过的是实际模式分支、原生结果与没有公开物理任务广播；日志未保存逐条 whisper 收件人详单，不扩展为对 PF2e 所有消息权限机制的审计。
