# 桌面骰盘 QA

日期：2026-10-01。候选版本：0.5.2，未发布。基于 `78c2839`，本轮修改托盘投影、几何和材质，未修改投掷物理及聊天同步流程。

## 设计和实现

| 项目 | 实现 |
| --- | --- |
| 观察角度 | 偏离正上方 55°，相当于桌面上方 35°；相机位于屏幕下缘一侧 |
| 左右环绕／画面旋转 | 0°／0° |
| 托盘相机 | 独立 PerspectiveCamera，35° FOV；托盘和 mini 骰子在同一场景渲染 |
| 原生相机 | 当前 DsN 的 20° FOV 保持不变；同一 box 的 projectionMatrix 和 matrixWorld 比对一致 |
| 托盘本体 | +Y 向上、水平底面，无 55° 本体旋转 |
| 盘沿 | 以直径 2 为单位，高 .11，名义径向宽 .10；八面等高，小倒角与内壁斜面 |
| 材质 | 哑光胡桃木、暗酒红内衬、很细的旧黄铜嵌线；几何倒角、灯光、粗糙度及轻微 bump |
| 木纹方向 | 每边独立 UV，U 沿边长，V 沿盘沿剖面；转角为分段拼接 |
| 合成 | 复用 DsN renderer，将本地场景绘制到一张缓存纹理，再交给原生场景合成 |

产品未新增 WebGL context、RAF 或持续绘制循环。独立场景在状态、模型和布局变化时更新。视图拥有自己的几何、材质、缓存目标和木纹贴图；mini 模型借用 DsN 几何与材质，移除时不 dispose 它们。

验收结束时已恢复 QA 世界的暂停状态，重新加载确认临时探针消失、会话计数为 0，关闭验收浏览器、隔离 QA 服务与本机 SSH 隧道。独立数据目录保留；两个既有生产进程均仍在运行，生产数据与配置未修改。

## 检查与审查

`npm test`：119/119；`npm run check` 与 `git diff --check` 通过。新增回归覆盖水平几何、盘沿法线与斜面、木纹 UV、视角共用、尺寸避让、renderer 状态恢复、DPR 和异步预览。

独立审查发现一个 Important：单个自定义骰模型加载失败会让成功的其他模型没有更新到缓存。已用两种失败顺序复现并补回归，改为等所有模型结束后绘制成功模型，再保留原来的失败通知。

审查保留一个 Minor：托盘中的静态 mini 不经过原生 selective bloom；启用发光骰样式时，光晕可能与原生投掷不同。原生投掷继续使用 DsN 的完整渲染流程。

发行和本地候选打包均已加入 `assets`，校验必需纹理非空、ZIP 完整性及文件字节一致；候选不包含测试、QA fixture、开发脚本或凭据。候选身份与 SHA-256 见本地 `qa/candidate-0.5.2.manifest.json`。

## 木纹资产与生成提示词

使用内置 `image_gen` 生成，最终文件为 `assets/textures/walnut-basecolor.png`，1254 × 1254 RGB，2317156 bytes，SHA-256 `1165b05b1268c6bf2b37484fb6ec507e81f4cc6b9cef7e9f01c15941a3b4c470`。

请求过 2048 × 2048，基础生成和一次定向编辑均返回 1254 × 1254；保留原生输出，没有用放大冒充 2K。图像也没有达到严格无缝边界：左右边界平均色差 6.62/255，内部相邻列为 2.77；上下为 8.02，内部相邻行为 7.56。当前每块盘沿采样一段完整纹理，不重复平铺；不能把它标成已验收的 2048 无缝素材。
